# TacticDev Assets

This directory contains media assets for the website.

## Video Background

The `ambient-bg.mp4` file should be a subtle, ambient video that:
- Is grayscale or near-grayscale
- Has minimal motion (slow pans, subtle movements)
- Loops seamlessly
- Is optimized for web (compressed, appropriate resolution)
- Enhances the technical, engineered aesthetic

The video is displayed at very low opacity (8%) and is grayscaled via CSS to maintain the quiet, minimal design.

If no video is provided, the site gracefully falls back to a subtle gradient background.
